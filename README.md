# Al-Qur'an (PWA)
Deploy: upload semua isi folder ini ke repo GitHub → Settings → Pages → Deploy from branch (main, / root).
Buka link `https://USERNAME.github.io/REPO/` di HP, lalu:
- iPhone (Safari): Bagikan → Tambah ke Layar Utama
- Android (Chrome): menu ⋮ → Instal aplikasi
API key (opsional) isi di konstanta `KEY` di index.html — di GitHub Pages key ini terlihat publik.
